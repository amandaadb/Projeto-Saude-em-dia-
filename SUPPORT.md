# Suporte - MedControl

> Guia rápido indicando onde usuários e colaboradores podem tirar dúvidas, relatar bugs ou pedir ajuda.

## Usuários

Caso tenha dúvidas, encontre algum problema ou queira relatar um bug, entre em contato pelo e-mail:

**amanda.db@uni9.edu.br**

Qual caminho seguir:

| Situação | Onde ir |
| :--- | :--- |
| Algo não funciona como esperado | Modelo de bug em **Issues**, ou o e-mail acima |
| Tenho dificuldade para usar o aplicativo | [ACCESSIBILITY.md](./ACCESSIBILITY.md) e o modelo de acessibilidade |
| Quero sugerir uma funcionalidade | Modelo de sugestão em **Issues** (veja antes o roadmap no [README.md](./README.md)) |
| Dúvidas sobre meus dados ou quero exercer meus direitos | [docs/privacidade.md](./docs/privacidade.md) |
| Encontrei uma falha de segurança | [SECURITY.md](./SECURITY.md). **Não abra issue pública** |

> Não inclua dados reais de saúde, senhas ou documentos em issues, prints ou e-mails.

## Colaboradores

Colaboradores do projeto podem tirar dúvidas ou reportar problemas diretamente pelo grupo do WhatsApp da equipe. Para contribuir, veja o [CONTRIBUTING.md](./CONTRIBUTING.md).

> O MedControl é uma ferramenta de organização e **não substitui orientação médica**. Em caso de dúvida sobre o seu tratamento, fale com um profissional de saúde.

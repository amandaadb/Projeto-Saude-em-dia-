# Componentes - MedControl

> Catálogo dos componentes reutilizáveis da interface (botões, cards de medicamentos, modais de alerta), garantindo consistência visual em todo o aplicativo.

## Componentes

| Componente | Uso | Situação |
| :--- | :--- | :--- |
| Botão | Ações principais e secundárias | A documentar |
| Campo | Entrada de dados nos formulários | A documentar |
| Card de medicamento | Exibição de cada medicamento | A documentar |
| Badge de status | Estado da dose e do estoque | A documentar |
| Modal de alerta | Avisos e confirmações | A documentar |
